Reference Guide

One brain, five rooms

Claude for Microsoft 365 isn't one tool — it's five separate products (Excel, Word, PowerPoint, Outlook, and Claude Tag for Slack) that share one Claude account and, when you turn on one setting, can read across each other's open files. This guide covers all five, with the exact prompts to use in each.

How to use this guide

Each app section follows the same shape:

  • What it's for — the kind of work this room handles best
  • A full walkthrough — a real example, start to finish, with every prompt you'd actually type

Before you install

1
A paid Claude planPro or Max for individual use; Team or Enterprise for org-wide rollout. The Free plan doesn't include any of these add-ins.
2
A genuine Microsoft 365 subscriptionPerpetual licenses like Office 2016 or 2019 aren't supported.
3
A supported app buildWeb always works. On desktop: Windows needs build 16.0.13127.20296+, Mac needs 16.46+ (16.61+ for Word specifically).
4
Admin consent for OutlookA Microsoft 365 Global Administrator needs to grant one-time consent before mail and calendar features work — this is separate from installing the add-in.

Installing an add-in

1
Go to Microsoft MarketplaceSearch “Claude for Microsoft 365.” Excel, PowerPoint, and Word share one listing; Outlook is a separate listing.
2
Click Get it nowThis adds the add-in to your Microsoft account.
3
Open the app and activate itHome → Add-ins on Windows, Tools → Add-ins on Mac.
4
Sign in with your Claude accountThat's it — no API key or config file needed.
Good to know

Only use these add-ins with files and senders you trust. A downloaded template or an unexpected attachment can carry hidden instructions — this is called prompt injection, and it's a real, documented risk, not a hypothetical one.

The Framework

RCTF — the four-part prompt

Every good prompt across all five apps has four parts. Skip one and you get a generic answer. Include all four and you get something you can actually ship.

Role

Who is Claude in this task? Not "an AI" — a specific persona. e.g. "a senior FP&A analyst"

Context

What isn't obvious from the file alone? e.g. "these tabs use inconsistent date formats"

Task

The actual instruction — specific, not vague. e.g. "clean, consolidate, and analyze"

Format

What should the output look like? e.g. "board-ready, IB formatting, with a waterfall chart"

Example prompt using RCTF

Role: You're a senior FP&A analyst reviewing this quarter's actuals. Context: This workbook has three regional tabs with inconsistent date formats. Task: Clean the dates, remove duplicates, and consolidate into one tab, then build a variance-to-budget summary. Format: Board-ready — IB formatting (blue inputs, black formulas), a summary table, and a waterfall chart of the three biggest variances.

You'll see this exact structure reused with different Role/Context/Task/Format combinations in every app section below.

Room 1 of 5

Claude for Excel

Generally availablePro · Max · Team · Enterprise

Claude for Excel reads your workbook like an analyst who's already memorized every formula dependency — it doesn't just answer questions, it edits cells directly, with every change traceable back to a citation.

Think of it like

Handing your workbook to an analyst who's memorized every formula dependency before you even asked — they trace what breaks three tabs away if they touch one assumption.

Walkthrough — cleaning a messy multi-region report

A regional actuals export with three tabs, inconsistent date formats, and duplicate rows.

Step 1 — Clean, consolidate, and build the analysis
Role: You're a senior FP&A analyst reviewing this quarter's actuals. Context: This workbook has three regional tabs — APAC, EMEA, Americas — with inconsistent date formats and at least two duplicate rows somewhere in the data. Task: Clean the dates to one consistent format, remove duplicate rows, and consolidate all three tabs into a single "Consolidated" tab. Then build a variance-to-budget summary table. Format: Board-ready — IB formatting (blue for hardcoded inputs, black for formulas), a summary table, and a waterfall chart showing the three biggest variances.
Step 2 — Trace and fix an error
Why is cell F12 on the Consolidated tab showing an error? Trace it and fix it.
Step 3 — Quick formatting one-liners
Sort the Consolidated tab by variance, descending.
Add conditional formatting: highlight any variance below -10% in red.
Add a dropdown for the "Status" column with options: On Track, At Risk, Critical.

More ways to use it

Turning raw transactions into a pivot summary+

Point Claude at a raw transaction export and get an instant breakdown by category, region, or rep — no manual pivot table setup.

Role: You're helping me analyze raw sales transactions. Context: Column D has product category, column F has region, column H has deal value. Task: Build a pivot summary of total deal value by category and region, and call out the single highest-performing combination. Format: A clean summary table plus a short written takeaway above it.
Building a headcount tracker with conditional formatting+

Useful for HR and team leads tracking open roles, offers, and start dates in one sheet.

Role: You're helping me build a headcount tracker. Context: I have a list of roles, hiring managers, status (Open/Interviewing/ Offer/Filled), and target start dates. Task: Build a tracker with a status column, and conditionally format overdue target dates in red and roles closing this month in yellow. Format: One clean sheet, sorted by target start date.
Forecasting next quarter from a trend+

Good for a first-pass forecast before a planning meeting — always double-check the assumptions Claude used.

Role: You're helping me build a simple forecast. Context: Column B has the last 6 months of revenue by month. Task: Project the next 3 months using a linear trend, and flag if the trend looks seasonal rather than linear. Format: A short forecast table plus a line chart, with your assumptions listed clearly underneath.
Good to know

No VBA, no macros, no Excel data tables. Not recommended for audit-critical numbers or a final client deliverable without a human review pass — treat the output as a fast first draft from a competent analyst, not a signed-off final number.

Room 2 of 5

Claude for Word

Generally availablePro · Max · Team · Enterprise

Claude for Word never touches your text silently — every suggestion shows up as a tracked change you can accept or reject, exactly like a colleague's redline.

Think of it like

A meticulous editor who never touches your document without leaving a paper trail — every suggestion is a tracked change, not an invisible rewrite.

Walkthrough — reviewing a redlined contract

A vendor NDA that came back with tracked changes, including one buried in the fine print.

Step 1 — Summarize what the other side changed
Role: You're reviewing this NDA on behalf of our legal team. Context: The counterparty just returned this document with fourteen tracked changes. Task: Summarize what they changed, grouped by severity, and flag anything worth pushing back on. Format: A short list — Dealbreaker / Worth Discussing / Harmless — one line per change.
Step 2 — Work through open comments
Work through my open comments. For each one, edit the anchored text as a tracked change, then reply to the comment thread explaining what you changed.
Step 3 — Draft new content in the existing style
Role: You're our HR policy writer. Context: Here's a rough bullet list for our new hybrid-work policy: 3 days in-office minimum, core hours 10am-4pm, manager approval for fully remote weeks, equipment stipend of $500/year. Task: Draft the full Hybrid Work section for our employee handbook. Format: Match the handbook's existing heading style, and add a summary table comparing the three work-mode options.
Step 4 — Semantic search across the document
Find every clause in this document that touches data retention, even if it doesn't use that exact phrase.

More ways to use it

Turning meeting notes into a formal clause+

Useful when a verbal agreement in a meeting needs to become precise contract language.

Role: You're drafting a contract amendment. Context: In our call, we agreed to extend the payment terms from Net 30 to Net 45, effective next quarter. Task: Draft a short amendment clause reflecting this, referencing the original agreement's section 4. Format: Match the formal tone and numbering style of the rest of the document.
Summarizing a long report into an executive brief+

Paste in a long report or paper and get a one-page summary without losing the key findings.

Role: You're preparing a briefing for a director who won't read the full report. Context: The attached document is 40 pages covering market research findings. Task: Summarize into one page — key findings, one risk, and one recommendation. Format: Short paragraphs, no more than 5 bullet points total.
Adjusting tone for a different audience+

Rewriting the same content for a client versus an internal team without changing the facts.

Role: You're adapting this internal update for an external client. Context: This memo was written for our internal team and includes casual language and internal project codenames. Task: Rewrite it for the client — remove internal codenames, keep the facts identical, make the tone more formal. Format: Same structure and length, client-appropriate tone throughout.
Good to know

Generally available on paid plans. Still not a substitute for a human review on client deliverables, litigation filings, or audit-critical documents. Accept tracked changes only after you read them. .doc files must be converted to .docx first.

Room 3 of 5

Claude for PowerPoint

Generally availablePro · Max · Team · Enterprise

Claude for PowerPoint reads your slide master before it builds anything — new slides already fit your brand's fonts, colors, and layouts.

Think of it like

A tailor who reads your template like a body measurement — builds new slides that already fit, instead of handing you something generic to force into shape yourself.

Walkthrough — building a QBR deck from a rough brief

A branded client template already open, and a handful of raw numbers.

Step 1 — Build the deck
Role: You're an account manager preparing this quarter's business review. Context: Here's the template, already open. Our numbers this quarter: MRR grew from $340K to $391K, churn dropped from 4.2% to 3.1%, but support ticket volume is up 22% — that's the one risk to flag. Task: Build a 6-slide QBR: title, agenda, 3 KPI-highlight slides (MRR, churn, support volume), and a next-steps slide. Format: One-line bullets only, use native PowerPoint charts (not images), and use the template's accent color for anything that beat target this quarter.
Step 2 — Make a pinpoint edit, not a full rebuild
Just rebuild slide 4. Make it about the support ticket increase — 22% up, flag it as the one risk, suggest we're adding a dedicated support hire.
Step 3 — Turn numbers into a native chart
Turn this into a chart: MRR by month — Jan 310K, Feb 322K, Mar 340K, Apr 355K, May 371K, Jun 391K.

More ways to use it

Turning a written document into a deck+

Great for turning a strategy doc or report into a presentable version for a leadership meeting.

Role: You're turning a written strategy document into a leadership presentation. Context: The attached document covers our 3 strategic priorities for next year. Task: Build an 8-slide deck — one title slide, one slide per priority with supporting detail, and a closing "asks" slide. Format: One core idea per slide, native charts wherever there's a number.
Building a competitive comparison slide+

Useful for sales decks where you need a clean side-by-side without building a table from scratch.

Role: You're building a competitive comparison slide for a sales deck. Context: We're comparing our product against two competitors on price, support hours, and integration count. Task: Build a single comparison slide, us in the middle column, highlighted. Format: A clean 3-column table with a checkmark/cross icon style, not plain text.
Turning a process description into a flow diagram+

Paste in a written process and get a visual flow instead of a paragraph.

Role: You're visualizing a process for a training deck. Context: Here's our onboarding process written out as a paragraph: [paste your process description]. Task: Turn this into a step-by-step flow diagram on one slide. Format: Numbered steps in connected boxes, left to right.
Good to know

Not recommended for final client-facing decks without a human review pass. Doesn't work on PowerPoint 2016/2019, iPad, or Android — web, Windows, and Mac only.

Room 4 of 5

Claude for Outlook

BetaPro · Max · Team · Enterprise

Claude for Outlook reads your whole inbox and sorts it before you sit down — but it will never once hit send without you looking first.

Think of it like

A sharp assistant who reads your inbox and sorts it into "needs you," "I drafted a reply, just check it," and "ignore" — but never sends anything on your behalf.

Walkthrough — a Monday-morning inbox triage

A full inbox, one real escalation buried inside it.

Step 1 — Triage everything unread
Role: You're my assistant this morning. Context: Everything unread in my inbox right now. Task: Sort into what needs me, what you can draft a reply for, and what's noise. Format: One-line reason for each item in the "needs me" bucket.
Step 2 — Draft the replies you can handle
Draft replies for everything you marked as "you can handle."
Step 3 — Summarize a long thread
What's been decided on this thread, and what's still open?
Step 4 — Prep for a meeting
Prep me for my 2pm with the client team.

More ways to use it

Drafting a follow-up sequence after a call+

Turns loose notes from a sales or client call into a ready-to-send follow-up.

Role: You're drafting my follow-up after today's client call. Context: We discussed pricing, a Q3 timeline, and they asked for a case study. Task: Draft a follow-up email covering all three points and proposing a next call. Format: Short, warm, no more than 150 words.
Summarizing a long CC thread before a meeting+

For threads with many participants where you need the gist, fast, before walking into a room.

Summarize this thread for someone who hasn't read any of it — what's the ask, who's blocking it, and what's the current state?
Handoff notes for someone covering your inbox+

Useful before time off — a clean brief for whoever's covering your inbox.

Role: You're helping me hand off my inbox for the week I'm out. Context: Everything unread and anything awaiting my reply. Task: Build a handoff brief — what needs attention, by when, and who to loop in for each. Format: A short list, most urgent first.
Good to know

There is no send permission at this beta stage — Claude cannot send an email or calendar invite. Everything lands unsent, waiting for you. Doesn't work on Outlook 2016/2019, iOS, Android, or on-prem Exchange.

Room 5 of 5

Claude Tag for Slack

BetaTeam & Enterprise only

Every app so far is a private notebook — Claude remembers you and your file. Claude Tag is a shared whiteboard: one Claude per channel, visible to the whole team.

Think of it like

A shared whiteboard bolted to the wall of a specific room — the whole team can see it, steer it, and hand off work to it, the way you'd hand something to a teammate.

Walkthrough — triaging bug reports in a channel

A #launch-readiness channel that gets bug reports throughout the day.

Step 1 — Give it a standing job
@Claude — a bug just got reported in this channel. Reproduce it if you can using our issue tracker and deploy logs, and if you find the root cause, open a draft PR.
Step 2 — A teammate picks up the same thread
@Claude — did you check if this is related to last week's caching change?

More ways to use it

Weekly standup summary+

Have Claude compile a running standup summary from a channel's activity instead of chasing updates manually.

@Claude — summarize what shipped this week in this channel and what's still open, then tag whoever owns each open item.
Onboarding FAQ helper+

Give new team members a place to ask questions without pinging a busy teammate directly.

@Claude — answer onboarding questions in this channel using our team wiki. If you're not sure, say so and tag [team lead] instead of guessing.
Cross-referencing a decision across channels+

Useful when a decision made in one channel needs to be checked against a related discussion elsewhere.

@Claude — did we already discuss this pricing change in the #leadership channel? Summarize what was decided there if so.
Good to know

Team and Enterprise only — not on Free, Pro, or Max, and not through Bedrock, Vertex, or Foundry. It replaces the older Claude in Slack app. An Owner pairs the workspace, connects tools, and sets a spend limit before the channel can use it. Claude cannot update a CRM, tracker, or repo unless that connector was granted to the channel.

Bringing It Together

Working across apps

One setting lets the four Office rooms read and write to each other's open files — so one sentence can move through Outlook, Excel, and PowerPoint without you copying a single number.

Turn it on

In each app’s Claude sidebar, open Settings and turn on “Let Claude work across files.” Pro and Max have this on by default. Team and Enterprise default to off, and an organization owner turns “Let Claude work across apps” on under Organization settings → Office agents. The toggle is per device, so turn it on in every app you want to coordinate from. Cross-app mode works when you sign in with a Claude account directly — not through Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry, or an LLM gateway.

Example — one prompt, three apps

Typed into the Outlook sidebar, with a blank Excel workbook and a branded PowerPoint deck already open.

Read the attached regional report. Build a variance-to-budget model for it in the open Excel workbook, then create a 5-slide client update in the open PowerPoint deck using the top 3 findings. Use the template as-is.

Good to know

Claude can only read and write files that are already open, plus the email or event currently open in Outlook. It cannot create, open, close, or switch files. Chat history stays in your browser and is not synced across devices — clear it from Settings. Skills you have enabled in Claude also apply while it moves across Excel, PowerPoint, Word, and Outlook.

Put It All Together

The Monday morning business review

One escalation email, five connected rooms, one hour. This is the workflow that uses everything in this guide at once.

1
Outlook — find the signalTriage the inbox and surface the one email that actually needs attention today.
2
Excel — build the modelTurn the attached report into a clean, cited variance model.
3
PowerPoint — make it client-readyTurn the top findings into a template-matched update deck.
4
Word — brief your teamDraft an internal memo summarizing the situation and your recommended talking points.
5
Claude Tag — loop everyone inPost a summary in your team's channel and tag whoever needs to review before the next call.

The internal memo prompt

Role: You're briefing your director before Friday's call with the client. Context: Use the variance findings from the open Excel model and the original escalation email thread. Task: Draft a one-page internal memo — what the client is concerned about, what the data actually shows, and your recommended talking points for Friday. Format: Match our team's existing memo template heading style.

The team loop-in prompt

@Claude — the client escalated about their numbers this quarter. Post a summary of what we found (the variance model and the client deck are both ready) and tag [teammate 1] and [teammate 2] to review before Friday's call.
