Core AIS concepts — review before the call

Logic Apps

Low-code workflow orchestrator. Consumption (serverless, pay-per-run) vs Standard (dedicated, stateful, VNet-integrated). Triggers + connectors + actions.

Service Bus

Enterprise message broker. Queues (point-to-point) vs Topics/Subscriptions (pub-sub). Sessions, dead-letter queues, at-least-once delivery.

Event Grid

Event routing, not messaging — reactive, push-based. Good for event-driven architecture: "something happened" not "process this data".

API Management (APIM)

API gateway: policies, rate limiting, versioning, developer portal, OAuth/subscription key auth. You completed training here — lean on it.

Functions

Event-driven compute for custom logic Logic Apps can't express cleanly. Consumption vs Premium vs Dedicated hosting plans.

Hybrid connectivity

On-premises Data Gateway (Logic Apps to on-prem), VPN Gateway vs ExpressRoute for network-level hybrid connectivity.
