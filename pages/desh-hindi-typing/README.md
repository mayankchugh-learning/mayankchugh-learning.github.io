# Desh Hindi Typing (Clone)

A frontend clone of [Desh Hindi Keyboard's Hindi Typing](https://www.deshkeyboard.com/hindi-typing/) editor.

## Features

- Hinglish → Hindi transliteration (Google Input Tools)
- Voice typing (Chrome Speech Recognition)
- Auto-saved drafts in `localStorage`
- Formatting toolbar, fonts, dark mode
- Marketing sections, FAQ, language links

## Run

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve desh-hindi-typing
```

Voice typing and clipboard need a secure context (HTTPS or localhost).
