How to use Desh Hindi for Hindi typing?

Type in English letters and the Hindi word will appear. This is English to Hindi transliteration. Press Space, Enter, or click a suggestion to commit.

I'm not able to use Hindi voice typing

Voice typing works best on Google Chrome browsers with microphone permission enabled.

Desh Hindi Online does not work properly on my phone

For the best mobile experience, download the Desh Hindi Keyboard app for Android or iOS.

Is Desh Hindi Keyboard safe?

This clone stores drafts only in your browser (localStorage). The live Desh Hindi tool uses an API for Hindi suggestions. See the Privacy Policy.
