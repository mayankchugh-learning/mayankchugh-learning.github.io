### Usage tips
- **Upload your headshot first** in the same chat/turn before pasting each prompt, since both ChatGPT and Gemini need the image attached to reference it.
- If a tool ignores the "don't alter the photo" instruction, try phrasing it as "insert this exact image as a circular avatar, unedited" — some models still stylize it.
- For **YouTube Shorts**, append: `Also provide a 60-second voiceover script, one sentence per slide.`
- For **LinkedIn carousels**, append: `Format this as an 6-8 slide swipeable carousel instead of a single frame.`
